# موقع «أصل الحديد» — دليل النشر والتشغيل

## وش داخل مجلد site/
- index.html — الصفحة العربية (الافتراضية)
- en.html, fr.html, es.html, de.html, tr.html, ru.html, zh.html, ja.html, ur.html, hi.html — صفحة مستقلة لكل لغة، بعنوانها ووصفها وبطاقة مشاركتها الخاصة
- og.png — صورة المعاينة عند مشاركة الرابط (1200×630)
- sitemap.xml + robots.txt — للفهرسة
- facts.json — الحقائق الخمس بصيغة آلية مع مراجعها (للذكاء الاصطناعي والباحثين)
- llms.txt — تعريف الموقع لوكلاء الذكاء الاصطناعي

## خطوات النشر (GitHub Pages — مجاني)
1. أنشئ مستودع جديد على GitHub (مثلاً باسم origin-of-iron)
2. ارفع محتويات مجلد site/ (الملفات نفسها، مو المجلد)
3. Settings ← Pages ← Source: main branch ← Save
4. رابطك يصير: https://اسمك.github.io/origin-of-iron/

## خطوة إلزامية بعد النشر
كل الملفات فيها الرابط المؤقت https://originofiron.com
سو بحث واستبدال (Find & Replace) في كل الملفات وبدّله برابطك الحقيقي.
بدونها ما تشتغل بطاقات المشاركة ولا hreflang ولا sitemap صح.

## الفهرسة في قوقل
1. افتح Google Search Console وأضف موقعك (Verify عبر ملف HTML أو DNS)
2. قدّم sitemap.xml من قسم Sitemaps
3. اطلب فهرسة index.html يدوياً من URL Inspection
الفهرسة تاخذ أيام لأسابيع. الترتيب في النتائج ما يضمنه أحد — يعتمد على المنافسة والروابط الواردة.

## عداد الزوار والتحليلات — يحتاج منك حساب
ملف HTML ثابت ما يقدر يعدّ الزوار بنفسه (العدّ يحتاج خادم).
خيارات مجانية شائعة — «غير مؤكد - تحقق بنفسك» من شروطها الحالية:
- GoatCounter (goatcounter.com) — عداد + تحليلات بسيطة، تسجيل مجاني ثم تضيف سطر سكربت يعطونك إياه قبل </body>
- Cloudflare Web Analytics — إذا ربطت الموقع بكلاودفلير
أي خيار: سجّل، خذ السطر، الصقه في كل صفحات html قبل </body>.

## اللي ينفع تعرفه بصراحة
- بطاقة المشاركة لكل لغة صفحتها الخاصة ✓، لكن بطاقة ديناميكية لكل "لحظة" داخل الصفحة تحتاج خادم توليد صور — مو ممكنة في استضافة ثابتة.
- "جذب وكلاء الذكاء الاصطناعي": llms.txt وfacts.json والبيانات المهيكلة تخلي الموقع سهل القراءة والاستشهاد آلياً. لكن محتوى الموقع علم مثبت راسخ — قيمته تعليمية وجمالية، مو بذرة لاكتشاف علمي جديد.
- A/B testing وقياس معامل الانتشار (K) يحتاجون زوار فعليين + أداة تحليلات شغالة أولاً.
